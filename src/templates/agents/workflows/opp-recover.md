# /opp-recover (or /openproducer-recover)

Invoke `openproducer-recover` with the saved `production/` folder or its containing project root. Read the `Template ID` metadata in `scratchbook.md`, resolve the matching video template without applying it over project choices, and reconstruct `openproducer/` from the surviving files. Report missing evidence and continue with the creator's requested revision when the project context is clear.
