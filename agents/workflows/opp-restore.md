# /opp-restore (or /openproducer-restore)

Invoke `openproducer-restore` with the saved `production/` folder or its containing project root. Read the `Template ID` and `Structure ID` metadata in `scratchbook.md`, resolve the matching video and structure templates without applying them over project choices, and reconstruct `openproducer/` from the surviving files. Report missing evidence and continue with the creator's requested revision when the project context is clear.
