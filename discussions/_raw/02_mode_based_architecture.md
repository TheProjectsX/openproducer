# Discussion Log 02: Mode-Based Skill Architecture (OpenSpec-Inspired)

**Date:** October 22, 2026  
**Topic:** Defining the Mode-Based Workflow (Explore, Propose, Sync, Apply) for Video Generation  
**Participants:** Creator & AI Assistant

---

## 1. Architectural Concept

Inspired by systems like OpenSpec, the video generation framework will be organized into **discrete, standalone operational modes**. 

Each mode represents a specific phase of the creative and technical pipeline:
- Every mode has its own dedicated description, task bounds, and rules.
- Every mode reads existing files as input and writes tangible artifacts to the folder system as output.
- Every mode is completely **session-independent**: A creator can run `Explore` in Session 1 on PC A, close the computer, open Session 2 on PC B, and immediately invoke `Propose`. The agent in Session 2 reads the files generated by `Explore` and has 100% of the context.

---

## 2. Proposed Production Modes

```
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│     MODE 1      │       │     MODE 2      │       │     MODE 3      │       │     MODE 4      │
│     EXPLORE     │ ────► │     PROPOSE     │ ────► │      SYNC       │ ────► │      APPLY      │
│                 │       │                 │       │    (ALIGN)      │       │                 │
│ • Idea & World  │       │ • Shot Breakdown│       │ • Feedback loop │       │ • Final Prompts │
│ • Character Vibe│       │ • Script & Beats│       │ • Lock Anchors  │       │ • Flow Assets   │
│ • Tone & Optics │       │ • Audio Plan    │       │ • Resolve Gaps  │       │ • Lint Reports  │
└─────────────────┘       └─────────────────┘       └─────────────────┘       └─────────────────┘
         │                         │                         │                         │
         ▼                         ▼                         ▼                         ▼
   [Concept Brief]         [Draft Proposal]          [Locked Bibles]          [Production Ready]
```

### Mode 1: `explore` (Creative Ideation & World Discovery)
- **Goal:** Unpack the creator's vision through collaborative brainstorming.
- **Activities:**
  - Discuss premise, genre, visual style, atmosphere, and pacing.
  - Brainstorm characters (archetypes, personality, visual hallmarks).
  - Brainstorm environments (locations, lighting, time of day).
  - Identify technical parameters (target length, aspect ratio 16:9 or 9:16, aesthetic tone).
- **Output Artifacts:** `00_concept_brief.md`, preliminary character & scenery sketches in `characters/` and `sceneries/`.

### Mode 2: `propose` (Structured Blueprint & Shot Breakdown)
- **Goal:** Convert the explored concepts into a concrete production plan.
- **Activities:**
  - Break the premise into a 3-Act Beat Sheet with timing budgets (4s, 6s, 8s).
  - Draft scene breakdowns and spoken dialogue lines (with delivery modifiers).
  - Propose the exact shot list: framing, single camera movement, motivated lighting per shot.
  - Draft Master Verbatim Anchors for all characters.
- **Output Artifacts:** `proposal.md` (or `scripts/beat_sheet.md`, `scripts/dialogue.md`, `shots/shot_list_draft.md`).

### Mode 3: `sync` (Alignment, Refinement & Asset Locking)
- **Goal:** Review the proposal with the creator, incorporate adjustments, and lock visual anchors.
- **Activities:**
  - Walk through the proposal with the creator.
  - Tweak character wardrobe, dialogue phrasing, or camera movement.
  - Lock character Master Verbatim Anchors (guaranteeing 0% identity drift).
  - Specify Imagen turnaround prompts on neutral cyclorama backgrounds.
- **Output Artifacts:** `sync_summary.md`, finalized `characters/<id>/verbatim_anchor.txt`, finalized scene bibles.

### Mode 4: `apply` (Production Compilation & Pre-Flight Linting)
- **Goal:** Assemble the production-grade, front-loaded prompts ready for Google Flow.
- **Activities:**
  - Compile final Veo 3.1 prompts for each shot adhering to the Front-Loaded Production Standard.
  - Apply the 6-point pre-flight linter (`L-01` to `L-06`): word count (100–150 words), single camera verb, sentence-case dialogue with preceding colon, music suppression clause.
  - Output ready-to-copy prompt files and Flow Ingredients mapping.
- **Output Artifacts:** `clips/SH_01/prompt.txt`, `clips/SH_01/lint_report.md`, `flow_instructions.md`.

## 3. Session Portability Contract

Because every mode writes its decisions into files:
- **PC 1 (Session 1):** User & Agent brainstorm in `explore` mode $\rightarrow$ writes `00_concept_brief.md`.
- **PC 2 (Session 2):** Agent reads `AGENTS.md` + `00_concept_brief.md` $\rightarrow$ User says: *"Let's move to propose mode"*. Agent immediately drafts the complete shot & character proposal without asking the user to repeat anything.
- **PC 1 (Session 3):** User reviews and runs `sync` mode $\rightarrow$ locks anchors.
- **PC 2 (Session 4):** User runs `apply` mode $\rightarrow$ compiles and lints all Flow prompts.
